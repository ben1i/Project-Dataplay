The True Size

of Video Games

In a moment, you'll be transported to a cinematic experience.

There's only ONE rule. As soon as the experience start, do not touch your mouse. The page scrolls by itself.

You'll be able to observe the size of your favorite games' maps. Each map will be downsized to a certain scale.

Each time the map change, you'll get a little question about the next game. Answer rightly and you'll get "juice" that you can exchange for a speed boost (you will need it)

Each map will also give you a little fun fact, like a size comparison with real countries, etc.
